# Agent Tutor practice project

This folder is an opt-in local agent practice project. These instructions apply only here.

When the user opens with a greeting, asks to start learning, or asks for guided help, activate the installed `agent-tutor` Skill and follow its opening menu and workflow. A greeting alone authorizes no file changes. If the Skill is unavailable, explain how to select or install it and offer the sample exercise in this chat without implying that the Skill ran.

Treat `example-notes.md` as read-only. Write exercises to new files only within this folder after the learner asks to create one, and check before replacing an existing file. Keep changes to global rules optional and require approval of the exact proposed edit.
