# Scenario: Office documents, forms, and meeting prep

Use this starter playbook when the learner wants to organize drafts, prepare for a meeting, or fill a structured form or template. Keep originals untouched unless the learner explicitly asks to edit them in place.

## Clarify first (1–2 questions max)

- Which file or material should we start from? If they have none ready, offer [the sample note](../../assets/practice/example-notes.md).
- What output format fits their use: an action checklist, a meeting agenda with open questions, a merged brief, a filled form draft, or a rewritten prompt only?

## Smallest workable deliverable

Deliver in the agreed format (a new file such as `todo.md`, `meeting-prep.md`, `merged-draft.md`, or `form-draft.md`, a chat draft, or a prompt only). Before writing a file, check whether the target filename already exists; if it is taken, propose a new name or ask before replacing it. Keep all source files read-only. If file writing is unavailable or not requested, deliver the draft directly in chat.

## Privacy and safety habit

When practicing with forms, resumes, contracts, or personal records, remind the learner to use redacted or sample information if they prefer, and never write sensitive personal details into persistent rules. For edits to an existing document, prefer generating a new copy or showing a clear preview first.

## Concrete learner check

Ask the learner to open the result (or review the chat draft) and check two things:

1. Are dates, owners, and open items consistent with the source material?
2. Did the original file remain unchanged?

## Optional next step

Invite one targeted revision (for example, "按负责人分组，并把未定事项单独置顶"). If that formatting preference is reusable, offer to save it via [saving feedback and rules](../saving-rules.md).
