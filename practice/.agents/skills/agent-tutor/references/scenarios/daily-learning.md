# Scenario: Daily planning and self-learning

Use this starter playbook when the learner wants to plan a trip or build a structured plan to learn a new skill or topic. When file writing is available and the learner wants a reusable plan, prefer saving a local file they can iterate on; if they asked for chat-only or prompt-only output, honor that choice.

## Clarify first (1–2 questions max)

- **Trip planning:** destination, trip length, rough budget, companions/pace, and any must-have or avoid items.
- **Learning a skill or topic:** target skill, current level, realistic time per day or week, and one concrete outcome they want to achieve.

## Smallest workable deliverable

Deliver in the agreed format (a clean Markdown file in the workspace, a chat draft, or a prompt only):

- For a trip (for example `trip-plan.md`): day-by-day itinerary, transport/time buffers, rough budget table, and an open decisions checklist.
- For learning (for example `study-plan.md`): a 7-day or milestone-based practice schedule, each step paired with a small hands-on exercise and a self-check question.

Before writing a file, check whether the target filename already exists; if it is taken, use a clearly stated new name or ask before replacing it. If file writing is unavailable or not requested, deliver the draft in chat. If live prices, opening hours, or schedules cannot be checked online, mark them explicitly as estimates to confirm.

## Concrete learner check

Ask the learner to inspect the plan, spot one constraint that does not fit their real life (such as daily pace, budget cap, or study hours), and give one short follow-up instruction to revise only that part.

## Optional next step

Show how to continue across sessions without losing context: if they want to pause and resume later, offer to append a 3-line handoff block at the bottom of the file (`已完成`, `待定选择`, `下一步`) so a fresh session can pick up cleanly.
