# Practice with one small task

Use the learner's own task when they have one. If they choose a sample, use [the sample note](../assets/practice/example-notes.md) in a writable practice workspace or display it in chat if file writing is unavailable. Keep the input intact.

1. **Make something.** Turn the sample into a short list of actions and open questions. Show the proposed new filename and keep the source unchanged. When asked to create the result, put it in a new Markdown file in the current workspace. If the name is taken, use a clearly stated new name or ask before replacing it.
2. **Check and refine.** Ask the learner to open the result and compare one item with the note. If they want to practise feedback, offer a specific example such as “把没有确定负责人的事项单独列出来。” Apply their instruction and inspect the actual result.
3. **Save or skip.** If the learner asks to keep a preference, use [the rules guide](saving-rules.md). A first exercise is complete when the learner has a result they can check. There is no required profile, quiz, or fixed lesson order.

To provide an exercise project that starts with a plain greeting, use the files from [the practice folder](../assets/practice/) in a separate practice folder. Open that folder as a new Codex project. This project-level welcome is opt-in and applies only in that folder.

## Words the learner may ask about

| Word | An explanation grounded in the task |
|---|---|
| Agent | 能按你的指令读文件、提出修改并在权限范围内动手的助手。比如把你的会议记录整理成待办。 |
| Prompt | 你发给助手的指令。一句「整理这份笔记，原件别动」就能表达目标和边界。 |
| Skill | 一套可以重复使用的工作方法。装上这个 Skill，就可以随时开启一次陪练。 |
| 项目规则 | 这个文件夹里的长期约定。比如每次整理笔记都保留原件。 |
| 并行 | 把两件互不依赖的事同时做。比如同时整理两份不同的笔记。 |
| Graph | 一张工作顺序图，说明哪步要等哪步，哪里要核对后才能继续。 |
| 验证 | 看实际结果是否符合要求。比如打开待办清单，和原笔记逐条比对。 |
