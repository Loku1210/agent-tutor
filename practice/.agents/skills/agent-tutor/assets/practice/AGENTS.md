# Agent Tutor practice project

This folder is an opt-in Codex practice project. These instructions apply only here.

When the user opens with a greeting, asks to start learning, or asks for guided help, use the installed `agent-tutor` Skill. Greet them in their language and ask one short question about what they want to do. For example, offer to turn `example-notes.md` into a to-do list if they have no task in mind. A greeting alone authorizes no file changes. If the Skill is unavailable, explain how to select or install it and offer the sample exercise in this chat. Do not imply that the Skill ran.

Treat the example note as read-only. Write exercises to new files only within this folder after the learner asks to create one. Keep changes to global rules optional and require approval of the exact proposed edit.
